Настройки

Подключение

Ключ хранится только в этом браузере и отправляется только на указанный адрес.

Ассистент

Уровень рассуждений теперь можно менять прямо в верхней панели чата. Поддержка зависит от модели; при ошибке 400 выберите «Авто».

Разрешения ИИ

Работает через OpenRouter Web Search. Модель сама решает, когда искать. Поиск может оплачиваться отдельно по тарифам OpenRouter/поискового провайдера. Запросы и контекст передаются провайдеру поиска. После согласия ИИ сможет запускать JavaScript для вычислений и проверки небольших фрагментов кода. Код запускается в отдельном изолированном iframe без доступа к API-ключу, файлам, хранилищу и сетевым запросам. Это не полноценный сервер или Python-среда. Не запускайте неизвестный код: бесконечный цикл может подвесить вкладку. Разрешение можно отозвать здесь же.

Память

Эти факты отправляются модели в каждом чате. Добавить факт можно здесь или фразой «запомни: …» в чате.
    Не записывайте сюда пароли и личные данные: на бесплатных серверах запросы могут сохраняться.

    Контекст и экономия

    Когда накопится столько, ИИ допишет к своему следующему ответу скрытый пересказ (отдельного запроса нет, бесплатные лимиты не тратятся). Старые сообщения перестанут отправляться, вместо них уходит пересказ. Сам чат на экране не меняется. Пересказ можно прочитать и поправить кнопкой «📝 Пересказ» вверху.
    Остаток аккаунта OpenRouter обычному ключу не отдаёт (нужен ключ управления), поэтому введите баланс со страницы openrouter.ai/settings/credits один раз. Дальше оболочка сама вычитает расход этого ключа. После пополнения введите баланс заново. Расходы других ключей аккаунта не учитываются. Пока баланс не введён, проверка не работает. Это только ваша страховка: решение всё равно принимает OpenRouter. Для моделей с «:free» проверка не нужна.
