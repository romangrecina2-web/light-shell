About the Project

This is an ultra-lightweight HTML-based AI interface. All you need to do is register at "openrouter.ai" (https://openrouter.ai), get your API key, copy it, and paste it into the settings.

An AI model is already configured by default, but you can change it to any model available on OpenRouter by simply entering its model ID in the API settings.

WARNING

The Story Behind the Project

One day, I (the lead developer) was running out of storage space, so I decided to clean up my device. Everything seemed important, so I eventually deleted my AI application.

But then I thought:

"Hmm, why do AI applications take up so much storage space?"

And that's how the Lightweight AI Interface project was born!

The application is less than 1 MB in size. It is written in HTML and can run even on low-end smartphones (including ultra-budget devices from 2018) and with slow internet connections (as low as 800 KB/s).

Project Goal

The goal of this interface is to make AI accessible even on low-end smartphones and slow internet connections.

The initial application size should not exceed 1 MB. As new features are added, the size may increase, but it will never exceed 50 MB.
